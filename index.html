Coverage

What the 40 cover

Grouped by what each program is actually teaching, not by which folder it happens to live in — the launcher sorts them into these buckets itself.

🕑

DSA & data structures

Bubble, merge and quick sort. Stack, queue, Huffman coding. Linear and binary search, plus BFS, DFS, Dijkstra and Kruskal on real graphs.

🧠

OOP concepts

Inheritance, method overloading and overriding, multiple inheritance, class objects and methods, method dispatch, static blocks and variables, encapsulation through the Employee and Student examples.

⚠

Core concepts

Exception handling and custom exceptions, plus an event-handling demo that shows the same idea with a listener behind it.

🔨

Basic practice

Factorial, primes, matrix addition and multiplication, max-min, array reversal, sum of naturals, a calculator, operators, class basics and sandglass patterns.

🏗

Standalone projects

Snake game, library management and a scientific calculator — the three that open a window, which is why batch runs skip them.

⚙

And a launcher

Pick by number, by range, by category or by name. Programs that need input get sample values filled in automatically so nothing hangs waiting for you.

How you actually use it

Copy, double-click, done

No install, no configuration, no dependency to download.

RUN_ME.bat 
REM Step 1 - download and unzip
REM   https://github.com/Abhijeet-Kumar-Prajapati/
REM     MULTIPLE-JAVA-PRACTICE-PROGRAMS---ALL-IN-ONE-LAUNCHER
curl -L -o JPP.zip https://github.com/Abhijeet-Kumar-Prajapati/MULTIPLE-JAVA-PRACTICE-PROGRAMS---ALL-IN-ONE-LAUNCHER/releases/download/v1.0.0/Java-Practice-Programs-1.0.0.zip

REM Step 2 - make sure java and javac are on PATH
java -version

REM Step 3 - double click RUN_ME.bat, or from a terminal:
RUN_ME.bat

That is the whole setup. The launcher finds the JDK, compiles what you picked into build/ and runs it. Output lands in build/run-all-output.txt so you can read the whole batch run afterwards.

Questions

Before you clone it

What do I need installed?

Only a JDK. Add bin to your PATH and the launcher finds java and javac on its own. There is no Maven, no Gradle and no library to download.

Can I run just one program?

Yes. Pick 1 in the menu and enter its number. You can also give several at once — 3,7,12 or a range like 5-9 or all.

Will it hang waiting for keyboard input?

No. Programs that read from Scanner get sample values filled in automatically when they are run as a batch, and every program has a five second limit so an accidental infinite loop shows up as a failure rather than a freeze.

Why are four programs skipped?

Snake game, library management, scientific calculator and event handling open a window. A window cannot open during a headless batch run, so they are listed but skipped. Run them from the menu by number when you are at a desktop.

Where does compiled output go?

Into build/, which is git-ignored. The full transcript of a RUN ALL session is written to build/run-all-output.txt, and the menu can reopen it for you.
